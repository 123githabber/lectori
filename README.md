# Lectorium

Одностраничный сайт-каталог лекторов: подбор эксперта, программы дисциплин, тарифы и форма заявки.

## Стек и версии

| Компонент | Версия |
| --- | --- |
| React | ^18.3.1 |
| React DOM | ^18.3.1 |
| Vite | ^5.4.11 |
| @vitejs/plugin-react | ^4.3.4 |
| Node.js | 18+ (проверено на v24.18.0) |
| npm | 10+ (проверено на 11.16.0) |

Стили — один глобальный CSS-файл `src/styles.css` без препроцессоров и CSS-фреймворков.
Роутинг и хранилище данных — собственная реализация, внешние библиотеки не используются.

## Команды для установки и запуска

```bash
npm install       # установка зависимостей
npm run dev       # dev-сервер с HMR, http://localhost:5173
npm run build     # продакшн-сборка в dist/
npm run preview   # локальный просмотр собранной версии из dist/
```

## Где лежат данные

Весь контент лежит в одном файле — `src/data.js`. Это обычные JS-массивы,
экспортируемые через `export const`, без запросов к API и без состояния на сервере:

| Экспорт | Строки | Что содержит | Где используется |
| --- | --- | --- | --- |
| `lecturers` | 1–633 | 10 лекторов: `name`, `photo`, `education`, `experience`, `degree`, `disciplines[]` (с `topics[]`), `tariffs[]` | `LecturerCard`, `LecturerSearch`, `Stats` |
| `partners` | 634–654 | Логотипы и описания партнёров: `name`, `logo`, `site`, `color`, `description` | `Partners` |
| `stats` | 655–661 | Цифры для блока статистики | `Stats` |
| `steps` | 662–668 | Шаги «Как это работает» | `HowItWorks` |
| `formats` | 669–674 | Форматы: онлайн, офлайн, корпоративный тренинг | `HowItWorks` |
| `values` | 675–681 | Ценности блока «О нас» | `About` |
| `faq` | 682–704 | Вопрос-ответ | `Faq` |
| `reviews` | 705–721 | Отзывы клиентов | `Reviews` |

Компоненты получают данные через пропсы: `Home.jsx` импортирует массивы из `data.js`
и передаёт их вниз (`<Partners partners={partners} />`), страницы — напрямую импортируют
`lecturers` из `data.js`.

Статические файлы (фото, логотипы) лежат в `public/images/` и подключаются по абсолютным
путям от корня сайта: `/images/lecturers/1.jpg`, `/images/partners/icl.png`.
В самом компоненте хранится только строка пути — сама картинка в `data.js` не вшита.

Чтобы добавить лектора или партнёра, достаточно дописать объект в соответствующий массив
в `src/data.js` и положить файл в `public/images/`.

## Где сделана навигация

Роутинг собственный, без `react-router`. Он основан на одном состоянии `page`
в `src/App.jsx:8` и принимает два значения:

| `page` | Что рендерится | Как попасть |
| --- | --- | --- |
| `home` | `<Home />` — главная со всеми секциями | по умолчанию; логотип, пункты «Главная / Партнёры / О нас», кнопка «Оставить заявку» |
| `lectors` | `<LecturersPage />` — каталог лекторов | пункт «Лекторы» в шапке, кнопка «Найти лектора» на первом экране, ссылки в подвале |

Механизм:

- `App.jsx:8` — `const [page, setPage] = useState('home')`, единственный источник правды о текущей странице.
- `App.jsx:29-39` — `Header`, `Home`, `LecturersPage` и `Footer` получают колбэки `onOpenLectors` (`setPage('lectors')`) и `onGoSection`.
- `App.jsx:10-17` — `goHomeSection(id)`: если открыта не главная, сначала переключает страницу на `home`, а затем прокручивает к нужной секции.
- `App.jsx:19-25` — `scrollToSection(id)`: для `main` скроллит вверх, иначе вызывает `scrollIntoView` у элемента с соответствующим `id`.
- URL не меняется, кнопка «назад» браузера работает как обычно — история не ведётся.

Якоря секций главной страницы (используются и в шапке, и в подвале):

| `id` | Секция |
| --- | --- |
| `main` | прокрутка наверх (не элемент, а специальный случай) |
| `partners` | Партнёры |
| `about` | О нас |
| `how` | Как это работает |
| `how-booking` | форма заявки внутри «Как это работает» |
| `booking` | Оставить заявку (отдельная секция ниже) |
| `lectors` | Наши лекторы |
| `lector-search` | поле поиска (на нём фокусируется страница при открытии) |

Секции-компоненты ставят себе `id` прямо в разметке (`<section id="about">`),
поэтому добавление нового раздела — это добавить `id` в компонент и кнопку в `Header`/`Footer`.

Строка поиска (`LecturerSearch`) — stateless: значение запроса и выбранная дисциплина
хранятся в `LecturersPage.jsx:8-9` и передаются вниз пропсами `query` / `onQuery` /
`discipline` / `onDiscipline`. Фильтрация — обычный `Array.prototype.filter` по `useMemo`
(`LecturersPage.jsx:27-42`). Открыта ли модалка бронирования — локальный `useState`
в `LecturerCard.jsx:5`. Весь этот локальный стейт сбрасывается при уходе со страницы.

## Подсказки стажа и учёной степени

В карточках лекторов наведите курсор на стаж или учёную степень либо выделите
поле клавишей Tab. Подсказка закрывается при уходе курсора и фокуса или по Escape.
У лекторов без учёной степени соответствующее поле не выводится.

`Tooltip.jsx` использует `createPortal(..., document.body)` и `position: fixed`.
Координаты вычисляются через `getBoundingClientRect()` и обновляются при прокрутке
страницы, вложенных контейнеров и изменении размера окна. Если сверху мало места,
подсказка появляется снизу; её положение ограничивается краями окна.

Для проверки откройте «Лекторы», наведите курсор на оба поля и прокрутите страницу.
Проверьте также Tab / Escape, узкое окно и `overflow: hidden` у родительского
контейнера: подсказка должна оставаться видимой за его пределами.
